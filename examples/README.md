# Example R scripts

In rsStudio, open the **Files** tab, browse to this `examples` folder, and click a `.R` file. Click inside the Source editor, press **Ctrl+A**, and click **Run selection / line** or press **Ctrl+Enter**. Results appear in the Console.

- `01-arithmetic.R`: creates variables and prints a sum of 15.
- `02-statistics.R`: calculates a mean and median of 80.
- `03-data-frame.R`: creates and filters a small table.
- `04-dplyr.R`: checks whether `dplyr` is available and filters a table if it is. Install `dplyr` through the Packages tab to run the package portion.

The scripts share the current R session, so variables remain available in the Console until R is restarted. The plot pane and data viewer are still in development.
